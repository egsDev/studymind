Supabase
Base de dados, autenticação e créditos
Passos no painel
  • ✓ Vai a supabase.com → New Project
  • ✓ Settings → API → copia URL e anon key
  • ✓ Authentication → Providers → activa Email
  • ✓ SQL Editor → corre o script abaixo
SQL — criar tabela user_credits
create table user_credits ( id uuid primary key default gen_random_uuid(), user_id uuid references auth.users(id) on delete cascade, plan text default 'free', used int default 0, reset_at timestamptz default (now() + interval '30 days'), stripe_customer_id text, stripe_sub_id text, updated_at timestamptz default now() ); alter table user_credits enable row level security; create policy "own" on user_credits for all using (auth.uid() = user_id);

Stripe
Produto, preço e webhook de pagamentos
Configurar produto
  • ✓ stripe.com → Products → Add product
  • ✓ Nome: StudyMind Pro · Preço: 8,00€/mês · recurring
  • ✓ Copia o Price ID → price_xxxxxxxx
Configurar webhook
  • ✓ Developers → Webhooks → Add endpoint
  • ✓ URL: https://teu-dominio.vercel.app/api/stripe-webhook
  • ✓ Eventos: checkout.session.completed
  • ✓ Adiciona também: customer.subscription.deleted
  • ✓ Copia o Webhook Secret → whsec_xxxxxxxx
⚠ Para testar localmente antes do deploy:
stripe login
stripe listen --forward-to localhost:3000/api/stripe-webhook
4
Variáveis de ambiente
Configura no .env.local e depois no painel do Vercel
NEXT_PUBLIC_SUPABASE_URL URL do projecto Supabase obrigatório
NEXT_PUBLIC_SUPABASE_ANON_KEY Chave anon (pública, segura no browser) obrigatório
SUPABASE_SERVICE_ROLE_KEY Chave service role — apenas no servidor só servidor
STRIPE_SECRET_KEY sk_live_... em produção / sk_test_... local só servidor
NEXT_PUBLIC_STRIPE_KEY pk_live_... (pública, segura no browser) obrigatório
STRIPE_PRICE_ID price_xxx do plano Pro obrigatório
STRIPE_WEBHOOK_SECRET whsec_... do endpoint de webhook só servidor
NEXT_PUBLIC_URL https://teu-projecto.vercel.app (para redirects)
Ficheiro .env.local
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc... SUPABASE_SERVICE_ROLE_KEY=eyJhbGc... STRIPE_SECRET_KEY=sk_test_... NEXT_PUBLIC_STRIPE_KEY=pk_test_... STRIPE_PRICE_ID=price_... STRIPE_WEBHOOK_SECRET=whsec_... NEXT_PUBLIC_URL=http://localhost:3000
⚠ Nunca faças commit do .env.local — adiciona ao .gitignore. No Vercel, as variáveis são configuradas no painel em Settings → Environment Variables.
5
Deploy no Vercel
Push para GitHub e deploy automático em segundos
Comandos Git + Vercel CLI
# 1. Inicializa git e faz primeiro commit git init git add . git commit -m "feat: studymind initial deploy" # 2. Cria repo no GitHub e faz push git remote add origin https://github.com/SEU_USER/studymind.git git push -u origin main # 3. No vercel.com: # New Project → Import → studymind # Settings → Env Variables → adiciona todas as vars # → Deploy! # Alternativa: Vercel CLI npm i -g vercel vercel --prod
Arquitectura final
🔄 A partir daqui cada git push main faz deploy automático. O Vercel trata do build, CDN e SSL.
